# Chronic Kidney Disease Prediction

## Project Overview
This project predicts Chronic Kidney Disease (CKD) using Machine Learning algorithms.

## Algorithms Used
- KNN (K-Nearest Neighbors)
- SVM (Support Vector Machine)
- XGBoost

## Dataset
Kidney Disease Dataset

## Features
- Data Preprocessing
- Missing Value Handling
- Label Encoding
- Data Visualization
- Model Training
- Accuracy Comparison
- Confusion Matrix
- PDF Report Generation

## Results
- KNN Accuracy: 98.33%
- SVM Accuracy: 100%
- XGBoost Accuracy: 97.5%

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- XGBoost
